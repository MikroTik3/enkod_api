<h1 align="start">Enkod Backend</h1>

Enkod Backend is the server-side application powering **[enkod.top](https://enkod.top)**.

It provides the API and backend infrastructure required to handle the application's business logic, data management, authentication, caching, and other server-side operations.

## Tech Stack

* **NestJS** — A progressive Node.js framework for building scalable and maintainable server-side applications.
* **Prisma** — A modern ORM used for database access and management.
* **Redis** — An in-memory data store used for caching and session management.
* **Docker** — Used for containerization and consistent development and deployment environments.
